# Colaberry AI Accelerator Program — Workspace

### [→ Open the Small Business KPI Copilot Command Center](https://pamy77.github.io/colaberry-architect-workspace/command-center/index.html)

The Command Center is the live status page for the **Small Business KPI Copilot** project — what's being built, which release is in progress, and what's actually live vs. still planned. It reads its data from [`.colaberry/plan.json`](.colaberry/plan.json) and [`.colaberry/progress.json`](.colaberry/progress.json) at runtime, so the link above always reflects the current state of this repo, no rebuild needed.

Start here: [`docs/workflow-plan.md`](docs/workflow-plan.md) — the plan the Command Center is built from.

This repo also holds other AI Accelerator Program exercises (architecture blueprints, skill labs, lessons) — see their own folders for details.
